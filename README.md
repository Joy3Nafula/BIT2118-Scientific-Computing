# BIT2118: Scientific Computing & Numerical Methods

Welcome to the BIT2118 Scientific Computing repository. This project contains a complete, practical suite of scientific computing solutions, numerical algorithms, and computational modeling simulations implemented in Python.

The repository spans key topics in scientific computation, ranging from fundamental floating-point arithmetic and vectorized linear algebra to advanced non-linear root finding, numerical calculus, ordinary differential equations (ODEs), constrained optimization, and stochastic Monte Carlo simulations.

## 📌 Repository Overview

This repository is structured as a module-by-module implementation of core numerical algorithms. Each task file is self-contained and includes:
* **Mathematical Formulation & Algorithm Logic:** Implementation of foundational algorithms using Python, NumPy, and SciPy.
* **Input/Output Analysis & Diagnostics:** Convergence checks, residual verifications, and error estimations against exact analytical solutions.
* **Data Visualization:** Graphical plots using Matplotlib to visualize data trends, fitting curves, trajectory intersections, and convergence behavior.
* **Real-World Application Scenarios:** Domain-specific adaptations (e.g., cloud computing load modeling, trajectory intersection analysis, chemical kinetics, thermal emergency simulations).
