# BIT2118-Scientific-Computing
BIT2118: Scientific Computing & Numerical MethodsWelcome to the BIT2118 Scientific Computing repository. This project contains a complete, practical suite of scientific computing solutions, numerical algorithms, and computational modeling simulations implemented in Python.The repository spans key topics in scientific computation,ranging from fundamental floating-point arithmetic and vectorized linear algebra to advanced non-linear root finding, numerical calculus, ordinary differential equations (ODEs), constrained optimization, and stochastic Monte Carlo simulations.📌 Repository OverviewThis repository is structured as a module-by-module implementation of core numerical algorithms. Each task file is self-contained and includes:Mathematical Formulation & Algorithm Logic: Implementation of foundational algorithms using Python, NumPy, and SciPy.Input/Output Analysis & Diagnostics: Convergence checks, residual verifications, and error estimations against exact analytical solutions.Data Visualization: Graphical plots using Matplotlib to visualize data trends, fitting curves, trajectory intersections, and convergence behavior.Real-World Application Scenarios: Domain-specific adaptations (e.g., cloud computing load modeling, trajectory intersection analysis, chemical kinetics, thermal emergency simulations).🛠️ Prerequisites & Environment SetupTo execute the scripts in this repository, ensure you have Python 3.8+ installed along with a virtual environment configured with the required scientific computing libraries.1. 📂 Catalog of Tasks & Numerical MethodsBelow is a detailed overview of the tasks implemented across the course modules:🔹 Module 1: Foundational Numerics & Linear AlgebraTask 03: Vectorization & Performance Benchmarking (Task_03_vectorization.py)Focuses on accelerating numerical calculations by replacing explicit Python loops with vectorized NumPy array operations ($\mathcal{O}(N)$ performance scaling).Task 04: Floating-Point Arithmetic & Error Analysis (Task_04_numerical_errors.py)Investigates IEEE 754 floating-point limitations, catastrophic cancellation, truncation errors, and machine epsilon ($\epsilon_{\text{mach}}$).Task 05: Matrix Algebra & Transformations (Task_05_matrix_algebra.py)Implements matrix multiplication, transposes, determinants, and spatial affine transformation matrices.Task 06: Systems of Linear Equations (Task_06_linear_systems.py)Solves linear systems $A x = b$ using matrix inverses and numerical linear algebra solvers (numpy.linalg.solve).Task 07: Gaussian Elimination & LU Decomposition (Task_07_gaussian_lu.py)Computes lower-upper factorization $A = P L U$ to efficiently solve multiple right-hand side systems without redundant triangular reduction.Task 08: Iterative Methods for Linear Systems (Task_08_iterative_linear.py)Solves large, sparse linear systems using iterative schemes such as Jacobi and Gauss-Seidel iteration.Task 09: Eigenvalues & Eigenvectors (Task_09_eigenvalues.py)Computes characteristic roots $\det(A - \lambda I) = 0$ and modal vectors for dimensionality reduction and stability analysis.🔹 Module 2: Non-Linear Equations & ApproximationTask 10: Root Finding: Bisection & Fixed-Point (Task_10_bisection_fixed_point.py)Implements bracketed root-finding via the Bisection method and iterative convergence via Fixed-Point Iteration $x_{n+1} = g(x_n)$.Task 11: Root Finding: Newton-Raphson & Secant (Task_11_newton_secant.py)Explores open root-finding techniques using derivatives ($x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$) and secant approximations.Task 12: Systems of Nonlinear Equations (Task_12_nonlinear_equations.py)Solves multi-variable non-linear residual systems $\mathbf{F}(\mathbf{x}) = \mathbf{0}$ using scipy.optimize.root (e.g., spatial trajectory intersections).Task 13: Interpolation Techniques (Task_13_interpolation.py)Constructs piecewise linear interpolation and smooth $C^2$-continuous cubic splines (scipy.interpolate.CubicSpline) to estimate missing intermediate data points.Task 14: Curve Fitting & Least-Squares Approximation (Task_14_curve_fitting.py)Performs non-linear least-squares optimization (scipy.optimize.curve_fit) to fit empirical models to noisy data and measure Root Mean Square Error (RMSE).🔹 Module 3: Numerical Calculus & Differential EquationsTask 15: Numerical Differentiation (Task_15_numerical_differentiation.py)Approximates continuous derivatives from discrete dataset logs using forward, backward, and $O(h^2)$ central finite difference methods.Task 16: Numerical Integration (Task_16_numerical_integration.py)Integrates discrete function profiles to compute cumulative quantities using the Trapezoidal rule ($\int_a^b f(x) dx \approx \sum \frac{f(x_i)+f(x_{i+1})}{2} \Delta x$) and Simpson's parabolic rule.Task 17: Ordinary Differential Equations: Euler's Method (Task_17_euler_ode.py)Solves first-order initial value problems (IVPs) $\frac{dy}{dt} = f(t, y)$ step-by-step using Euler's update formula $y_{n+1} = y_n + h f(t_n, y_n)$.Task 18: Advanced ODE Solvers with SciPy (Task_18_scipy_ode.py)Employs adaptive explicit Runge-Kutta integration methods (scipy.integrate.solve_ivp) with tight relative/absolute error tolerances for complex physical models.🔹 Module 4: Optimization & Stochastic ModelingTask 19: Constrained Numerical Optimization (Task_19_optimization.py)Solves constrained operational cost minimization problems using Sequential Least Squares Programming (SLSQP) via scipy.optimize.minimize.Task 20: Random Numbers & Monte Carlo Simulations (Task_20_monte_carlo.py)Leverages pseudo-random sampling from normal distributions ($N = 100,000$) to calculate probability distributions, risk bounds, and convergence behavior.🚀 Running the TasksYou can execute any individual script directly from your terminal. For example:# Run the Systems of Nonlinear Equations task

# Run the Monte Carlo Simulation task
